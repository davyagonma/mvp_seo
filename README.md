# MVP SEO

A minimal viable product (MVP) for SEO automation, built with Python.

## Features

- Automates SEO tasks using Python scripts.
- Easily customizable for various SEO workflows.
- Simple command-line interface.

## Usage

1. Clone the repository:
    ```bash
    git clone https://github.com/davyagonma/mvp_seo.git
    cd mvp_seo
    ```

2. Install dependencies:
    ```bash
    pip install -r requirements.txt
    ```

3. Run the application:
    ```bash
    python app.py
    ```

## Configuration

- Edit `app.py` to customize SEO tasks as needed.
- Add your own modules or scripts for extended functionality.

## Requirements

- Python 3.7+
- See `requirements.txt` for dependencies.
